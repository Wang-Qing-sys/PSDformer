
PSDformer Full Reproduction Framework

Based on the manuscript:
Long-Term Stress Conditions Assessment and Prediction of Drivers Based on a Hybrid Deep Learning Framework and Novel Sensor System.

Implemented modules:
1. Dimension-wise Segmentation Window (MDSW)
2. Temporal and Cross-dimensional Dependency Extraction (TDE)
3. Encoder Decoder Module (EDM)
4. Dense Graph Convolution (DGC)
5. Stress prediction head

The framework follows the described architecture and provides extensible PyTorch code.
