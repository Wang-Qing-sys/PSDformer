## 2. 自动化测试覆盖

### 模型与数学结构

- 完整默认模型前向和反向：输入 `[B,T,D]`，预测 `[B,K,O]`，可选 logits `[B,C]`。默认模型有 897,234 个可训练参数。
- 小模型、多输出变量、奇数输入长度/预测长度、批量为 1、单通道、单步预测均通过；分类头设为 `None` 或 `0` 可关闭。
- MDSW 确实按各变量独立分段，无时间/变量混合；不完整末段零填充；固定二维位置编码区分两个轴。
- 实际 hook 验证 TDE 时间注意力输入为 `[B*D,L,E]`；路由器收集/分发的 Q/K/V 分别按 `[B*L,R,E]` 和 `[B*L,D,E]` 排列。路由器获得有限、非零梯度。
- 合并采用相邻时间段拼接；奇数末段按约定复制。四层奇数测试的段数为 `5 -> 3 -> 2 -> 1`。
- 各解码层预测逐元素求和；独立验证该和与 `edm_forecast` 完全一致，并直接传入 DGC。
- DGC 有两个密集块；实际卷积输入通道依次为 `1,5,9,13` 的测试配置证实复用了全部前层特征。不同短预测长度和池化宽度不产生空时间轴。
- 梯度到达嵌入、初始 TDE、深层编码器、解码器、DGC 和输出头；单次 Adam 步确实改变参数。
- 批量样本之间不交换信息；单独运行各样本和合并批量运行得到一致输出。

### 缺失值、损失与指标

- 掩码为 False 的隐藏值即使改为巨大数字也不改变输出，且这些输入的梯度为零。
- NaN、正无穷、负无穷按缺失输入处理；全缺失输入仍产生有限输出。这里验证的是边界健壮性，不代表缺失数据下的有效预测能力。
- 连续目标中的非有限值和标签 `-1` 被明确忽略；先选择有效目标再计算误差，避免 NaN 反向传播。
- forecast-only 不要求分类标签或分类头；classification-only 不使用缺失的连续目标；joint 同时训练两项。
- 完全无监督的批次产生有限的图连接零损失；非法权重、非法类别和已观察位置的非有限预测会报错。
- 不等大小批次的 epoch 损失按实际有效目标数加权，不错误地平均各批次均值。
- 手算验证 MAE、MSE、RMSE、R²，以及稿件定义的 `RSE = sqrt(SSE/(n_valid-2))`。例子明确区分 RSE 与 RMSE。
- `n_valid <= 2` 时 RSE 未定义，恒定目标的 R² 未定义；内部为 NaN，报告输出采用 JSON null。
- 手算验证分类混淆矩阵、macro precision/recall/F1、准确率与 NLL；不以合成分类准确率是否达到某阈值判定通过。

### 数据、泄漏防护与命令行

- 受试者划分可复现、互不重叠且覆盖所有数据；重叠、重复、未知或未分配受试者会被拒绝。
- 输入和连续目标的归一化分别只拟合训练受试者；极端偏移的留出数据不会重新拟合归一化器。
- 常数训练变量使用安全缩放；完全无观测的训练变量明确报错，不捏造统计量。
- 打乱 CSV 行次序后，按受试者/会话分组及时间排序；窗口不跨边界。
- CSV 连续目标严格来自输入结束后的行；分类标签来自最后一个输入时间点。重复时间戳会报错。
- classification-only CSV 不要求无用的未来行；未标注推理 NPZ 不要求目标或类别。
- 完整 CLI joint 演示、forecast-only 训练/评估/预测、classification-only 训练/评估/预测均实际执行；仅导出已训练任务的输出。
- 保存的最佳 checkpoint 由验证集指标决定；验证阶段优化器步数为零。
- 重载 checkpoint 后 CSV 预测逐字节一致；独立前向结果与导出值一致。
- 评估指标由恢复原始单位后的预测和目标计算；归一化空间误差没有冒充原始单位误差。
- 新的未标注数据可以 `predict --partition all`；改变数据后不能冒充原 checkpoint 的 test 集，指纹校验会拒绝。
- 所有 CLI 子命令的 help 均可运行。

## 3. 保留的默认演示结果

使用随包默认 `smoke.json`，未更改模型或训练配置：

- 29,950 参数的小模型，包含完整 MDSW → TDE → EDM → 两块 DGC → 双任务头路径
- 6 个合成受试者，每人 5 个窗口，共 30 个窗口
- train/val/test 为 4/1/1 个受试者；对应 20/5/5 个窗口
- lookback 24，预测长度 3，5 个输入变量，1 个连续输出，3 个合成类别
- 2 个训练 epoch，6 次实际 Adam 更新；选择第 2 个 epoch
- 训练总损失：2.093337 → 2.031610
- 验证总损失：1.742613 → 1.732026
- 与同 seed 初始化相比，163 个浮点状态张量发生变化，绝对变化量总和 71.953228
- 输入和目标归一化参数与独立重算的训练集统计完全一致
- 保存后重载生成的 CSV 与原演示 CSV 逐字节一致

`metrics.json` 内的数值只是这个小型合成运行的执行产物，**不是实际司机压力检测质量，也不是论文实验结果**。不同 PyTorch 版本或硬件可能产生轻微浮点差异。
